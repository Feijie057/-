# 蓝海 & 红海行业 · AI 使用场景与工作流细化

> 版本：2026-09 ｜ 承接：[《企业 AI 化转型 · 行业细分分析》](enterprise-ai-industry-analysis.md) 第 5 节四象限
>
> - **蓝海区**（低渗透 / 高潜力）：制造业、医疗健康与生命科学、能源与公用事业、交通物流
> - **红海区**（高渗透 / 中潜力）：传媒营销、教育、电信
>
> 本文对 7 个行业逐一做三件事：**① 行业再细分 → ② 提炼 AI 使用场景 → ③ 拆解可落地的工作流**。
> 场景成熟度与价值判断基于公开案例与行业研究的综合判断，用于规划参考，不代表具体企业的实测数据。

## 阅读说明

### 工作流卡片格式

每条工作流按统一格式拆解，便于直接转化为项目需求：

| 字段 | 含义 |
|---|---|
| **触发** | 什么事件启动这条工作流 |
| **流程** | 按顺序的步骤；`[AI]` = AI 自动完成，`[人]` = 人工处理/审核，`[系统]` = 现有业务系统动作 |
| **涉及系统** | 需要打通的业务系统 |
| **角色** | 参与或受影响的岗位 |
| **衡量指标** | 上线后用于判断效果的指标 |

### 场景成熟度标记

- 🟢 **成熟**：已有大量规模化案例，可直接采购或复制
- 🟡 **成长**：有标杆案例，需要结合企业数据做定制
- 🔴 **前沿**：技术可行但落地案例少，适合有实力的企业探索

### 蓝海与红海的打法差异

| | 蓝海行业 | 红海行业 |
|---|---|---|
| 核心矛盾 | 数据基础弱、场景分散、行业 Know-how 门槛高 | 工具同质化、价格战、用户已被"教育"过 |
| 机会来源 | 从 0 到 1：把 AI 接进物理世界和专业流程 | 从 1 到 N：做深场景、做通流程、做出效果差异 |
| 切入策略 | 先"单点高价值场景"证明 ROI，再平台化 | 从"工具"升级为"端到端工作流 / Agent" |
| 关键能力 | 数据采集与治理、OT/IT 融合、合规认证 | 垂直数据、闭环效果、交付与运营 |
| 竞争壁垒 | 行业数据 + 场景理解 + 客户关系 | 私域数据 + 工作流嵌入深度 + 结果付费 |

# 第一部分 · 蓝海行业

## 1. 制造业

### 1.1 行业细分

| 细分领域 | 代表行业 | 生产特征 | AI 核心机会 |
|---|---|---|---|
| **离散制造 · 汽车及零部件** | 整车、动力电池、零部件 | 多品种、长供应链、高自动化 | 视觉质检、柔性排产、供应链协同、研发仿真 |
| **离散制造 · 电子/半导体** | 消费电子、PCB、芯片封测 | 高精度、高良率要求、数据丰富 | 良率分析、缺陷检测（AOI 复判）、设备 FDC |
| **离散制造 · 装备制造** | 工程机械、机床、电力装备 | 小批量、定制化、服务周期长 | 设计复用、售后远程诊断、备件预测 |
| **流程制造 · 化工/石化** | 炼化、精细化工 | 连续生产、高危、工艺复杂 | 工艺参数优化（APC）、安全预警、配方研发 |
| **流程制造 · 钢铁/有色/建材** | 钢铁、铝、水泥 | 高能耗、高温、设备重载 | 能耗优化、炉况预测、质量软测量 |
| **流程制造 · 医药/食品** | 制药、食品饮料 | 强合规（GMP）、批次管理 | 批记录审核、偏差调查、质量追溯 |
| **轻工/纺织/家居** | 服装、家具、家电 | 中小企业多、季节性强 | 设计生成、需求预测、C2M 定制 |

### 1.3 核心工作流

**WF-M1 · 视觉质检闭环**（对应 M-01）
- **触发**：工件到达检测工位
- **流程**：工业相机采图 `[系统]` → 缺陷检测与分类 `[AI]` → 置信度低或疑似缺陷转人工复判 `[人]` → 复判结果回流为标注数据，定期再训练模型 `[AI]` → 按班次生成缺陷分布与趋势报告 `[AI]` → 工艺工程师根据异常趋势调整工艺 `[人]`
- **涉及系统**：机器视觉平台、MES、QMS
- **角色**：质检员（从"看"变成"复判"）、工艺工程师、质量经理
- **衡量指标**：漏检率、过检率（误报）、质检人力、一次合格率

**WF-M2 · 预测性维护 → 维修执行**（对应 M-02、M-03）
- **触发**：传感器数据出现异常趋势
- **流程**：采集振动/温度/电流数据 `[系统]` → 异常检测与剩余寿命预测 `[AI]` → 自动生成预警工单，附故障可能原因与处理建议（检索手册与历史维修记录）`[AI]` → 设备主管确认并排入检修计划 `[人]` → 维修工现场通过对话助手查询步骤、备件 `[AI+人]` → 维修结果与经验自动归档入知识库 `[AI]`
- **涉及系统**：IoT 平台、EAM/CMMS、备件库存、知识库
- **角色**：设备工程师、维修工、备件管理员
- **衡量指标**：非计划停机时长、MTBF、MTTR、备件库存周转

**WF-M3 · 质量问题 8D 闭环**（对应 M-10）
- **触发**：客户投诉或内部质量异常
- **流程**：汇总投诉描述、检测数据、生产批次记录 `[AI]` → 检索历史相似问题与处理方案 `[AI]` → 生成 8D 报告初稿（D1–D4：团队、问题描述、临时措施、根因假设）`[AI]` → 质量工程师验证根因、确定纠正措施 `[人]` → 自动跟踪措施执行与验证 `[AI]` → 结案并沉淀为经验库 `[AI]`
- **涉及系统**：QMS、MES、CRM（客诉）、文档系统
- **角色**：质量工程师、客户质量代表
- **衡量指标**：8D 结案周期、问题重复发生率

**WF-M4 · 流程工业工艺优化**（对应 M-04、M-05、M-12）
- **触发**：实时生产运行（持续）
- **流程**：采集 DCS 实时数据 `[系统]` → 软测量推算关键质量指标 `[AI]` → 优化模型给出参数调整建议（收率/能耗/质量多目标）`[AI]` → 操作员确认后下发（初期开环建议，成熟后闭环自动）`[人]` → 效果回溯与模型校准 `[AI]` → 生成班组绩效与能耗日报 `[AI]`
- **涉及系统**：DCS、APC、实时数据库、MES、能源管理系统
- **角色**：操作员、工艺工程师、能源管理员
- **衡量指标**：收率、单位能耗、质量波动（标准差）、操作员调整频次

**WF-M5 · 智能排产与交付承诺**（对应 M-06、M-07）
- **触发**：新订单进入 / 每日排产
- **流程**：需求预测与订单汇总 `[AI]` → 考虑产能、物料、换线成本生成排产方案 `[AI]` → 计划员调整特殊订单 `[人]` → 物料齐套检查与缺料预警 `[AI]` → 自动给销售反馈可承诺交期 `[AI]` → 插单/设备故障时实时重排 `[AI]`
- **涉及系统**：ERP、APS、MES、WMS、SRM
- **角色**：计划员、销售、采购
- **衡量指标**：订单准时交付率、设备利用率、换线时间、库存周转天数

**WF-M6 · SOP 与作业指导书生成**（对应 M-14）
- **触发**：新产品导入 / 工艺变更
- **流程**：输入工艺路线、图纸、BOM `[人]` → 生成作业指导书初稿（含步骤、要点、安全注意）`[AI]` → 工艺工程师审核 `[人]` → 自动生成多语言版本与培训题库 `[AI]` → 发布到车间终端 `[系统]` → 一线员工通过问答助手随时查询 `[AI]`
- **涉及系统**：PLM、文档管理、培训系统
- **角色**：工艺工程师、班组长、一线员工
- **衡量指标**：文件编制周期、新员工上岗培训时长、作业错误率

## 2. 医疗健康与生命科学

### 2.1 行业细分

| 细分领域 | 主体 | 特征 | AI 核心机会 |
|---|---|---|---|
| **医院 · 临床诊疗** | 三级/二级医院临床科室 | 医生时间最稀缺、责任重大 | 病历生成、影像辅助、临床决策支持 |
| **医院 · 医技科室** | 放射、病理、检验 | 数据高度数字化、标准化 | 影像/病理 AI、报告生成 |
| **医院 · 运营管理** | 医务、医保、病案、信息科 | 规则密集、文档量大 | 病案质控、DRG/DIP 编码、医保审核 |
| **基层医疗与互联网医疗** | 社区卫生中心、线上问诊平台 | 医生资源不足 | 辅助诊断、分诊、慢病管理 |
| **制药 · 研发** | 药企、Biotech、CRO | 周期长（10 年+）、投入大 | 靶点发现、分子设计、临床试验优化 |
| **制药 · 注册与商业化** | 药企注册、医学、市场部门 | 文档与合规极重 | 申报文档撰写、药物警戒、医学信息 |
| **医疗器械** | 器械厂商 | 需注册审批 | AI 医疗软件（SaMD）、手术机器人 |
| **医保与商保** | 医保局、保险公司 | 欺诈与控费压力 | 智能审核、反欺诈 |
| **健康管理** | 体检中心、健康管理公司 | C 端、长周期 | 报告解读、个性化健康干预 |

### 2.2 AI 使用场景清单

| H-04 | 临床决策支持（CDSS） | 临床诊疗 | 知识图谱 + LLM | 辅助诊断、用药提醒 | 🟡 |
| H-05 | 智能导诊分诊 | 门诊、互联网医疗 | 对话式 AI | 减少挂错号、分流患者 | 🟢 |
| H-06 | 病案质控与 DRG/DIP 编码 | 运营管理 | NLP + 规则引擎 | 减少编码错误与医保拒付 | 🟡 |
| H-07 | 医保智能审核与反欺诈 | 医保、商保 | 规则 + 机器学习 | 识别违规与欺诈 | 🟢 |
| H-08 | 患者随访与慢病管理 | 基层、健康管理 | 对话 AI、风险预测 | 提高随访覆盖率、降低再入院 | 🟡 |

| H-10 | 临床试验患者招募 | 制药、CRO | NLP 病历匹配 | 缩短入组时间 | 🟡 |
| H-11 | 注册申报文档撰写 | 制药注册 | LLM | CSR、CTD 模块初稿生成 | 🟡 |
| H-12 | 药物警戒（不良事件处理） | 制药 | NLP 信息抽取 | 自动识别、编码、报告 ADR | 🟡 |
| H-13 | 医学文献与竞品情报 | 制药医学、市场 | LLM + 检索 | 文献综述与情报追踪 | 🟢 |
| H-14 | 体检报告解读 | 健康管理 | LLM | 个性化解读与健康建议 | 🟢 |
| H-15 | 医院内部知识与制度问答 | 全院 | RAG | 规章、诊疗规范快速查询 | 🟢 |

### 2.3 核心工作流

**WF-H1 · 门诊病历自动生成**（对应 H-01）
- **触发**：医生开始接诊（经患者知情同意）
- **流程**：录制医患对话 `[系统]` → 语音转写并区分说话人 `[AI]` → 结构化提取主诉、现病史、既往史、体格检查、诊断、处置 `[AI]` → 生成符合病历书写规范的初稿 `[AI]` → 医生核对修改并签名 `[人]` → 回写 HIS/EMR，同时生成患者版就诊小结 `[AI]`
- **涉及系统**：HIS、EMR、语音采集终端
- **角色**：门诊医生、患者
- **衡量指标**：单份病历书写时间、病历完整率、医生日均接诊量、医生满意度

**WF-H2 · 影像检查 → 诊断报告**（对应 H-02、H-03）
- **触发**：影像检查完成上传 PACS
- **流程**：影像自动预处理与病灶检测（如肺结节、骨折）`[AI]` → 按危急程度对工作列表重新排序，危急值优先 `[AI]` → 生成结构化报告初稿（病灶位置、大小、性质描述）`[AI]` → 放射科医生阅片、修改、签发 `[人]` → 随访病灶自动与历史影像对比 `[AI]` → 报告推送临床 `[系统]`
- **涉及系统**：PACS、RIS、HIS
- **角色**：放射科医生、临床医生
- **衡量指标**：报告出具时长（TAT）、危急值通知时间、检出率、漏诊率

**WF-H3 · 出院病案质控与 DRG 入组**（对应 H-06）
- **触发**：患者出院、病案提交
- **流程**：读取病历全文与费用明细 `[AI]` → 检查病历缺陷（缺项、矛盾、时限）`[AI]` → 推荐主诊断与主手术编码，模拟 DRG/DIP 入组 `[AI]` → 提示高倍率/低倍率病例与潜在拒付风险 `[AI]` → 编码员与医生确认修正 `[人]` → 上传医保 `[系统]`
- **涉及系统**：EMR、病案系统、医保结算系统
- **角色**：编码员、临床医生、医保办
- **衡量指标**：病案甲级率、编码准确率、医保拒付金额、病案归档时长

**WF-H4 · 临床试验患者招募**（对应 H-10）
- **触发**：新临床试验启动
- **流程**：解析试验方案中的入排标准 `[AI]` → 在合作医院脱敏病历中筛选潜在受试者 `[AI]` → 生成候选名单及匹配理由 `[AI]` → 研究医生核实 `[人]` → 生成通俗易懂的知情同意说明材料 `[AI]` → 患者沟通与入组 `[人]`
- **涉及系统**：EMR（脱敏数据）、CTMS、EDC
- **角色**：研究者、CRC、申办方
- **衡量指标**：入组周期、筛选失败率、入组人数达成率

## 8. 可复用的 AI 工作流模式

7 个行业共 34 条工作流，可归纳为 6 种通用模式。**同一模式的技术底座可以跨行业复用**，这是方案规模化的关键。

| 模式 | 结构 | 代表工作流 | 核心技术 | 人的角色 |
|---|---|---|---|---|
| **① 感知检测型** | 采集 → 识别 → 分级 → 人工复核 → 回流训练 | 视觉质检 WF-M1、线路巡检 WF-E1、影像诊断 WF-H2 | 计算机视觉 | 复判与兜底 |
| **② 预测优化型** | 数据 → 预测 → 优化方案 → 人工确认 → 执行 → 复盘 | 预测维护 WF-M2、功率预测 WF-E2、排产 WF-M5、运力计划 WF-L4 | 时序预测、运筹优化 | 决策确认 |
| **③ 文档生成型** | 多源资料 → 抽取 → 生成初稿 → 合规校验 → 人工审核 → 归档 | 8D 报告 WF-M3、病历 WF-H1、两票 WF-E3、报关 WF-L2、售前方案 WF-T4 | LLM + RAG | 审核签字 |
| **④ 知识问答型** | 知识沉淀 → 检索 → 回答 → 反馈 → 知识更新 | 维修助手 WF-M2、运维助手 WF-T1、SOP 问答 WF-M6 | RAG | 提问与纠错 |
| **⑤ 对话服务型** | 意图识别 → 自助处理 → 转人工（带摘要）→ 质检 → 优化 | 客服 WF-T2、异常件 WF-L3、招生 WF-D4、随访 WF-H6 | 语音 + 对话 AI | 处理复杂例外 |
| **⑥ 内容生产型** | 需求 → 多版本生成 → 审核 → 分发 → 效果回收 → 迭代 | 电商内容 WF-C1、广告创意 WF-C2、课程生成 WF-D3、备课 WF-D1 | 多模态生成 | 挑选与把关 |

## 9. 场景优先级建议

按 **"价值 × 可行性"** 给出各行业首批推荐落地的场景：

| 行业 | 首批落地（3–6 个月见效） | 第二批（6–12 个月） | 长期布局（12 个月+） |
|---|---|---|---|
| 制造业 | 视觉质检、SOP 生成、维修知识助手 | 预测性维护、8D 闭环、智能排产 | 工艺闭环优化、生成式设计、具身智能 |
| 医疗健康 | 病历生成、院内知识问答、医学文献 | 病案质控/DRG、影像报告生成、随访 | CDSS、AI 药物发现 |
| 能源 | 规程问答、巡检报告生成、功率预测 | 智能巡检、两票校核、设备诊断 | 调度辅助决策、虚拟电厂 |
| 交通物流 | 客服查件、单证识别、路径优化 | 异常件闭环、运力匹配、仓内优化 | 供应链控制塔、自动驾驶 |
| 传媒营销 | 文案/图片生成、合规审核、舆情监测 | 短视频自动化、投放优化闭环 | AI 短剧/视频全流程、智能 NPC |
| 教育 | 备课、出题、作业批改 | 学情分析、企业培训陪练 | 自适应学习、课堂分析 |
| 电信 | 智能客服、告警压缩、基站节能 | 故障自愈、防流失、售前方案 | 高等级自智网络、算力服务 |

## 10. 落地检查清单

每条工作流上线前逐项确认：

- [ ] **数据**：输入数据是否已数字化、可合规获取、质量达标？
- [ ] **边界**：哪些步骤 AI 自动完成，哪些必须人工确认？出错的代价是什么？
- [ ] **集成**：结果能否自动回写业务系统，而不是停留在一个独立页面？
- [ ] **评测**：是否有测试集和上线后的效果指标？基线数据是否已采集？
- [ ] **闭环**：人工修正的结果是否回流，用于持续改进？
- [ ] **合规**：是否涉及个人信息、行业准入（医疗器械、电力安全规程等）、AIGC 标识？
- [ ] **组织**：岗位职责是否相应调整？使用者是否接受过培训？
